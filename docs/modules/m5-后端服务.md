# M5 后端服务

## 目标

用 HTTP 暴露模型：活着、就绪、模型说明、单条与批量预测；错误要说清是哪个字段，预测要留痕。

## 验收

- `.venv\Scripts\python.exe -m bank_api` 起服务，`/health` 200、`/ready` 200、`/v1/model` 返回版本/指标/15 字段说明、`/docs` 可打开。
- `POST /v1/predict`：返回 `score/level/factors/advice`；越界（年龄 999）返回 422，`loc=["body","年龄"]`；未知枚举、缺字段同理。
- `POST /v1/predict/batch`：上限 100（`configs/api.yaml`），超限 422，空列表 422。
- 每条预测追加一行到 `data/processed/predictions.jsonl`（`prediction_record.v2`：`ts/contract/request_id/model_version/score/level/control/features_hash/quota_frac/quota_n`，只留输入指纹、不写客户特征值）；对照组按 `sha256(seed:request_id)` 确定性抽 10%（ADR 0014）。
- `GET /metrics`：`service_metrics.v1`（请求数、路由/状态码分布、预测数、等级分布、平均/最大延迟、模型版本、重载统计）；每请求比对 `current.json` 文本，变了才整包重载，坏包保留旧模型（ADR 0015）。
- 模型包缺失时：`/health` 仍 200、`/ready` 与 `/v1/model` 503、进程不退出。
- 契约：`docs/architecture.md` §4.4、§4.5；决策：`docs/adr/0007-服务契约与错误码.md`。
- 测试：`tests/service/test_api.py` 13 项（含 NaN 必须 422 而不是 500）、`tests/contract/test_openapi.py` 6 项、`test_hot_reload.py` 4 项、`test_metrics.py` 6 项。

## 不做

- 不做登录/鉴权/限流（课程场景，内网演示）。
- 不用数据库存预测记录（jsonl 足够）。
- 不在 api 里 import 训练代码（预处理与解释已在 core）。
- 不自定义 422 的错误体结构（沿用 FastAPI 的 `detail[].loc/msg`）。
