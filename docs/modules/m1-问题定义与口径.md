# M1 问题定义与口径

## 目标

在动手建模之前，把「预测什么、用哪些列、什么时候切分、多少名额、怎么算成功」定死，让后面所有数字都有同一把尺子。

## 验收

- 一句话定义与模板逐项对照：`docs/problem.md`。
- 17 列逐列判定（可用 / 派生 / 禁用）、派生列定义、切分口径、名额口径、E1–E5 对照实验：`docs/spec.md`。
- 数据卡（来源、许可、时间轴证据、漂移表、泄漏证据、限制）：`docs/data_card.md`。
- 踩坑清单 9 条：`docs/pitfalls.md`。
- 决策记录：`docs/adr/0001-数据集与行数口径.md`、`docs/adr/0002-时间切分与建模窗口.md`。
- 文档里每个数字都能用 `.venv\Scripts\python.exe -m bank.profile` 复现（45,211 / 5,289 / 21,093 / 4,109 / 356 / 泄漏 AUC 0.8076）。

## 不做

- 不训练模型、不写服务（属于 M3/M5）。
- 不做特征工程之外的清洗（清洗规则在 M2，命中行数进台账）。
- 不为了「更好看的指标」改窗口：窗口与时点是答辩必问项，改了就写新 ADR。
