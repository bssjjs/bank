# M2 数据管道

## 目标

从唯一的只读原始入口，按时间顺序重建时间轴、跑清洗台账、生成派生列、按时间切分，并把结果冻结成可跨机器复现的两张表加两份指纹文件。

## 验收

- 只读入口：`packages/core/src/bank/raw.py`（`mode=ro` + `PRAGMA query_only=ON`），全仓再无第二个 `sqlite3.connect` 读原始库。
- 时间轴：`timeaxis.py` 强制首月、同月日号不回退、跨月只允许 12→1，`tests/unit/test_timeaxis.py` 14 项。
- 清洗台账：`clean.py` + `rules.py` 共 7 条规则，不删行，命中数与致命/记账分开；实测 45,211 → 21,093 只来自窗口裁剪，清洗只命中 5 行（R3 记账）。
- 切分：`split.py` 断言训练与验证不重叠、切点前后无漏行；缓冲 0 天且切点落月份边界（ADR 0002）。
- 冻结：`python -m bank.freeze` 打印 21,093/4,109、17,537/2,327、3,556/1,782、名额 356；重跑 `FROZEN.json` 的 sha256 不变；`--check` 通过。
- 契约：`manifest.v1` 字段见 `docs/architecture.md` §4.1。
- 测试：`tests/unit/test_freeze.py` 27 项。

## 不做

- 不悄悄删行、不填补「未知」。
- 不做特征选择（那在 M3，用训练集内层验证做）。
