# X10 前端页面（扩展）

> 任务书基础模块的 **M6 是模型解释**（见 `docs/modules/m6-模型解释.md`）；本页是扩展 X10，负责人自己写。页面代码在 `apps/web/`，已提交。

## 目标

让人在网页上填一条客户信息，看到分数、等级、主要因素与用途提示；出错时错在哪个输入框要看得出来。

## 验收（已实现）

- 表单字段**不写死**：`fetch("/v1/model")` 读 `inputs[]`（15 个字段的类型、范围、枚举、中文名）动态生成。
- 结果卡：分数、等级、top 5 因素（中文特征名 + 取值 + 贡献方向）、用途提示（`advice`）。
- 字段级错误：把 422 的 `detail[].loc[1]` 映射回输入框并显示 `msg`。
- 服务状态：启动时探 `/health` 与 `/ready`，未就绪时禁用提交并提示。
- 视觉：人民币红背景、五角星淡水印、左上现代门楼、右上 `￥`、底部标语；装饰层 `pointer-events: none`，不挡表单操作。
- 结果等级按接口返回的 `level`（`优先` / `备选` / `不建议`）显示，不用 0.5 阈值自行判断。
- 只走 HTTP：不 import 任何 Python 包，不本地算分。

## 不做

- 不做登录、权限、多语言。
- 不在前端做特征工程或本地模型推理（口径必须唯一）。
- 不做路由/状态管理框架（一个页面够用）。
- 不引入构建链（若做，纯 HTML + 原生 `fetch` 即可；技术栈与否的取舍要补 ADR）。
