# M4 模型包与版本

## 目标

把「一个训练好的模型」变成服务能安全加载、前端能生成表单、出问题能一键回退的版本化产物。

## 验收

- `.venv\Scripts\python.exe -m bank_training.export --version 1.1.0` 输出模型包摘要：特征 21 列、必填输入 15 列、切点 优先 0.57298 / 备选 0.253228、AP 0.6498、run_id、`current.json` 指向。
- `models/serving/<版本>/` 只有 `bundle.json` 与 `model.joblib`；同版本号不能二次写入；失败不留半个目录（staging + 原子改名）。
- `load_bundle` 校验：`bundle.json` 校验和、模型文件 size 与 sha256、缺列拒绝。
- 发布门禁：特征 ≥10、AP ≥0.50、名额内精确率 ≥0.60、ROC-AUC > 0.5，不过门禁不写版本。
- 回退：改 `current.json` 指回旧版本，不删目录、不改包内文件。
- 契约：`docs/architecture.md` §4.3；决策：`docs/adr/0006-模型包与发布.md`。
- 运行时血统：`bundle.json` 记 python / sklearn / pandas / numpy 四版本，加载前比对 sklearn 主次与 Python 主版本，不一致拒绝加载（ADR 0020）。
- 版本状态机与审计：`bank/registry.py` 四状态、门禁先行、审计先行、`rollback` 只改指针（ADR 0013）；`export` 默认只登记 `candidate`，`--promote` 才上线。
- 测试：`tests/unit/test_bundle.py` 17 项（含 5 项运行时闸门）、`tests/unit/test_registry.py` 10 项。

## 不做

- 不做模型注册中心服务（版本状态机以目录 + `current.json` 表达）。
- 不做多版本并行流量（在线 A/B 见 `docs/architecture.md` §7.2）。
- 不在包里存训练代码或数据：服务只需 `bank` 包即可推理。
