# M3 训练与评估

## 目标

在同一份验证集、同一个名额下，给出两条基线和一个主模型，指标带口径、能解释、能复现，并把每次训练记成一条可查的运行记录。

## 验收

- `.venv\Scripts\python.exe -m bank_training.train` 打印四个模型的 AP / ROC-AUC / 名额内精确率 / 名额内召回率 / Brier，并把 4 个 run 写进 `mlflow.db`（实验 `bank-marketing`）。
- 主模型 LR + 特征集 B：AP 0.6498、名额内精确率 0.7416、召回 0.1481、Brier 0.2852，名额 356 人打中 264 人。
- 规则基线：AP 0.6412、名额内精确率 0.7640、Brier 0.4924。
- 对照实验 E1–E5：`.venv\Scripts\python.exe -m bank_training.experiments`，结果回填 `docs/spec.md` §6。
- 单条解释：`packages/core/src/bank/explain.py`，返回 top 5 因素。
- 模型卡：`docs/model_card.md`；取舍：`docs/adr/0005-模型选择.md`。
- 测试：`tests/unit/test_training.py` 11 项。

## 不做

- 不用验证集调参、选模型、定名额（调参只用训练集内层滚动验证）。
- 不追模型分数：换主模型的唯一门槛是 AP 高 ≥0.03 且名额内精确率高 ≥2pp。
- 不装 shap：逻辑回归的线性贡献与之等价，且避免拉 numba 降级 numpy。
- 不做前端展示（M6）。
