# ADR 0012：校准只报告不拟合，切片按名额比例分配

- 状态：已采纳
- 日期：2026-11-24
- 相关：ADR 0002（时间切分）、ADR 0005（模型选择）、ADR 0011（评估报全）、`docs/model_card.md`

## 背景

讲义第三轮卷一 C-L3a 要求回答两个问题：**分数准不准**（校准）、**模型对谁不够好**（切片）。
我们的处境有两个特殊点：

1. 训练期正例率 13%、验证期 50%，模型平均分 0.272 而验证集基率 0.501——概率系统性偏低。
   直觉的修法是拿验证集拟合一个 Platt/Isotonic 校准器，但那是**用验证集调参**，
   违反 ADR 0002（验证集只评不调），也是任务书一票否决项。
2. 名额是全局的 356 人，切片之后每个切片该分到多少人没有天然答案。

## 决定

### 一、校准：出证据，不出校准器

- 每次训练对主模型算可靠性表（10 箱）、ECE、Brier、平均分与基率之差、最偏的一箱，
  写进 `data/processed/evaluation_report.md` 并记进 mlflow run。
- **不拟合**任何校准器；模型卡与报告里都要写清「分数是排序分，不是校准概率」。
- 要校准的时机只有一个：PSI 告警、线上攒够回流标签之后，在**线上数据**上单独做，
  并写新 ADR（把「用什么数据、怎么验证」写下来）。

### 二、切片：名额按人数比例分配，小切片不报

- `k_slice = max(1, min(n_slice, round(n_slice × 名额比例)))`，与全局名额同一比例。
- 少于 100 人的切片不报（表里留一行说明谁被跳过）；理由：名额只有个位数时，
  精确率的方差大到没有解释价值。
- 切片维度取原始业务列：职业、教育程度、联系方式、婚姻状态、年龄档（5 档粗分箱），
  全部来自 `configs/features.yaml`，不新造特征。
- 每片报：人数、基率、名额、名额内精确率/召回率、AP。

## 否掉的方案

| 方案 | 为什么否 |
| --- | --- |
| 用验证集拟合 Platt / Isotonic | 等于拿验证集调参，违反 ADR 0002，也是一票否决项 |
| 只报整体指标、不做切片 | 讲义要求回答「对谁不够好」，答辩会问「联系方式=未知 那 253 人你怎么办」 |
| 切片名额按固定人数（比如每片 30 人） | 人数不同的切片不可比；比例分配才让每片回答同一个问题 |
| 切片名额按各片最优取满（每片取到基率匹配） | 那是按评估结果回头改口径，属于调参 |
| 用模型分数给切片排序、只报前几片 | 会让读者以为「只差这几片」，掩盖长尾 |

## 后果

- `train.py` 每次多跑约 0.1 秒算校准表与五张切片表，报告变长约 120 行。
- 报告与模型卡里出现「联系方式=未知 名额内精确率 0.1200」这种难看数字——**这是要的**：
  它把「未知渠道的人模型排不出来」这件事摆到桌面上，运营据此单独处理该档。
- 新增 10 项单测（校准 5、切片 5），总数 240 → 250。
- 可靠性表与切片表的数字全部由 `python -m bank_training.train` 现场生成，
  基线封条不抄这些数字（它们是评估产物，不是第一轮结论的封条）。
