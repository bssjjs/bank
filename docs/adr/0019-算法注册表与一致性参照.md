# 0019 算法注册表与一致性参照

- 状态：已采纳（2026-11-24）
- 对应讲义：第二轮卷一 C-L2b「新增算法只加一个文件」
- 相关：ADR 0005（模型选择）、`packages/training/src/bank_training/algorithms/`、`baselines/v1/algorithm_parity.json`

## 背景

C-L2b 的要求是：加一种算法不能改一堆地方，而且加进去的算法要能被证明"跑出来的就是该跑出来的"。原来的实现把 `lr` 与 `rf` 写在 `pipeline.py` 的 `if/elif` 里，`configs/model.yaml` 的 `kind` 用 `Literal["lr","rf"]` 卡死——加一种算法要动三处（pipeline、Literal、测试），而且没有任何东西能发现"有人改了共享预处理，把原来的算法跑歪了"。

## 决定

1. **一个文件一种算法**：`packages/training/src/bank_training/algorithms/` 下每个文件用 `@algorithm("名字")` 登记，`linear.py`→`lr`、`forest.py`→`rf`。登记文件由包在第一次用到时用 `importlib` 自动导入（不在 `pipeline.py` 顶部写 import，否则 `linear.py` 反过来用 `build_preprocessor` 会撞上半初始化的模块）。
2. **`pipeline.build_model` 只做分发**；`configs/model.yaml` 的 `kind` 改成普通字符串，由 `ModelConfig` 去注册表里核对，报错时列出可用名字。加算法不再需要改任何枚举。
3. **一致性参照先冻结**：`python -m bank_training.parity --write` 在冻结集上把每个登记过的算法各训练一次，记下 AP / ROC-AUC / 名额内精确率 / 名额内召回率 / 名额内人数，**外加逐条分数的指纹**（`%.10g` 拼文本再 sha256，与内容指纹同一套小数口径），写 `baselines/v1/algorithm_parity.json`，由 `scripts/freeze_baseline.py` 的封条一起管。
4. **`--check` 的判据**：四项指标容差 `1e-6`、名额内人数必须完全相等、逐条分数指纹必须相同；多出没进参照的算法也报错（先 `--write` 并说明为什么）。
5. **契约测试参数化**（`tests/contract/test_algorithms.py`，14 项）：注册表自检（名字合规、不许重名、文件与登记一一对应、`MODEL_KINDS` 与注册表一致）＋ 每种算法两次训练逐位相同（atol=0，不许有隐藏随机性）＋ `--check` 必须通过 ＋ 容差与人数判据的单测。

## 为什么还要记「逐条分数指纹」

指标相同不代表挑出来的是同一批人：同 AP 的两份分数，名额内的 356 人可能换了十几个。人数一样、精确率一样、召回率一样，唯一的差别藏在"哪 356 个人"里。指纹就是冲着这个漏洞去的。

## 参照「独立于框架」的边界（如实说）

讲义希望参照实现本身不依赖框架（例如用 numpy 重写逻辑回归，再和 sklearn 比）。这一轮**没做**那一步，理由：

- 逻辑回归用 lbfgs 收敛，重实现的迭代步数/收敛判据不同，概率差很容易超过 1e-6，会把"真错"和"浮点差异"混在一起；
- 本机没有第二个数值库可做交叉验证，写一个 numpy 版再和它自己比是同义反复。

代替它的是两条更强的工程约束：**同一算法两次训练逐位相同**（消除隐藏随机性）、**换机器复跑分数指纹相同**（消除环境差异）。这条取舍写在这里，答辩时按"没做"回答，不说成"做到了"。

## 否掉的方案

- 继续在 `pipeline.py` 里加 `if/elif`：加一种算法要改三处，且没有一致性检查。
- 用 `entry_points` 或放到 `models/plugins/`：`models/` 不进 Git，参照与插件会跟着"本机才有的文件"走。
- 参照写成"每次跑出来的当前值"：那就不是参照，是自证。
- 只比指标不比分数：见上一条「哪 356 个人」。

## 后果

- 加算法 = 写一个文件 + 跑 `parity --write` 并说明为什么 + 重新冻基线封条；`configs/model.yaml` 不用改结构。
- `rf` 在特征集 B 上的数是 **AP 0.6455 / ROC-AUC 0.6427 / 名额内精确率 0.7640 / 召回 0.1526**，和它在特征集 A 上的 0.6229/0.6024/0.7500/0.1498 不是同一组，报告里别混用。
- 训练层多一条命令（第 20 条），质量门时间 +约 40 秒（`--check` 要重训两个算法）。
