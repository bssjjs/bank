# A3 · 配置加载（`bank/config.py` + `bank/yamlkit.py`）

## 1. 这个模块是什么

口径数字的唯一出处：窗口起止、切点、缓冲期、名额比例、种子、特征集、标签列。代码里不许再写一份。
读法不是"读出字典再 `.get()`"，而是**读出即校验**：多一个键、少一个键、值越界、重复键、日期写错，
都在启动那一秒报错，并指出是哪个键。

## 2. 谁用它

`freeze.py`（窗口/切分/特征集/种子）、`split.py`（切点与名额）、`dataset.py`（标签列）、
`train.py`（种子、名额）、`scripts/freeze_baseline.py` 与 `freeze.check()`（配置指纹）。

## 3. 输入

`configs/base.yaml`（或测试里临时写的同类文件）。结构固定为八段：
`schema_version` / `seed` / `data` / `window` / `split` / `quota` / `features` / `target`。
`data.raw_table` 必须与 `schema.RAW_TABLE` 一致，`target.column` 必须与 `schema.TARGET_RAW` 一致。

## 4. 输出

`Config`（pydantic 模型，`frozen=True`，不可在运行时改）+ `config_fingerprint(cfg)` 的 sha256。

## 5. 契约（公开接口）

```python
CONFIG_PATH: Path
class ConfigError(RuntimeError)      # 读不动 / 不合规，统一这一个异常
class Config(BaseModel)              # 段：data / window / split / quota / features / target
load_config(path: Path = CONFIG_PATH) -> Config
config_fingerprint(cfg: Config) -> str
quota_size(n_valid: int, cfg: Config) -> int
```

## 6. 错误与边界

| 情况 | 行为 |
| --- | --- |
| 文件不存在 | `ConfigError`，消息里带完整路径 |
| YAML 语法错 / 顶层不是映射 | `ConfigError`（由 `YamlError` 包装） |
| 同一层出现重复键 | `ConfigError: 键重复：'seed'（同一层里出现了两次）`——YAML 默认会"后者覆盖前者"，那是最难查的一类错 |
| 多了不认识的键（如 `cutt`） | `ConfigError`，消息里出现 `cutt`（`extra="forbid"`） |
| `window.start >= window.end` | `ConfigError: window.start 必须早于 window.end` |
| `split.cut` 不在窗口内 | `ConfigError: split.cut 必须落在 window 内部且晚于起点` |
| `buffer_days` 越界（负或 >365） | `ConfigError`，带 `buffer_days` |
| `quota.frac` 不在 `(0,1]` | `ConfigError`，带 `quota.frac` |
| `target.window_days != 0` | `ConfigError`：本数据集通话结束即得标签，等待窗口只能是 0（ADR 0002） |
| 日期写成 `2009-13-01` | `ConfigError`：`yamlkit` 把 PyYAML 的 `ValueError` 包成带文件名的错误 |
| 空验证集 | `quota_size` 抛 `ValueError("验证集为空，名额无从谈起")`，不返回 0 |

## 7. 不做什么

- 不做环境变量覆盖、不做多环境继承（实验级差异走 `bank_training/experiments.py` 的参数，不复制整份配置）；
- 不做热加载：进程起来后配置就固定，改配置必须重启——拍卖场景里"线上口径悄悄变"比"重启"危险；
- 不校验业务分布（比如"正例率是否合理"）：那是数据卡与质量门的事。

## 8. 怎么验收

```powershell
.venv\Scripts\python.exe -m pytest tests/exam/test_config_exam.py -q     # 18 题
.venv\Scripts\python.exe -m pytest tests/unit/test_config.py -q          # 单测
```

考卷覆盖：拼错键、重复键、非法日期、冻结不可改、四类越界、标签窗口必须为 0、
配置指纹不认注释只认值、名额 `ceil(3556×0.1)=356`。

## 9. 为什么这样定

- **为什么用 pydantic 而不是自己写 if**：`extra="forbid"` + `frozen=True` 是两条现成的保险，
  自己写容易漏掉"嵌套段里的未知键"。
- **为什么重复键要单独拦**：PyYAML 默认不报错，"写了两遍 seed，第二个生效"会让指纹与人对配置的理解不一致。
- **为什么配置指纹只算值不算注释**：注释变了不代表口径变了；但值一变，指纹必须变，否则"这批结果基于哪份配置"无从对账。
- **为什么 `buffer_days` 还在（当前是 0）**：切分要留缓冲这个机制对别的任务必要（标签有成熟期），
  本数据集恰好不需要；保留字段而不是删掉，是为了让"缓冲期为什么是 0"成为一条可写的决策，而不是一个隐形的省略。
