# C-L2c 模型比规则强多少、名额要不要放宽

- **目标**：在同一验证集上把主模型（逻辑回归 + 特征集 B）与规则基线并排比，名额当自变量取 10% / 15% / 20% 三档，报每档抓到多少正例、精确率与召回，并如实写结论（包括「模型没比规则多抓人」这种不好看的话）。
- **验收**：`python -m bank_training.compare` 打印六行三档结果并写 `data/processed/compare.md` 与 `compare.json`；`python -m pytest tests/unit/test_compare.py -q` 8 项全过；`docs/adr/0017-模型与规则的名额取舍.md` 记两条结论；`scripts/ci.py` 末行「质量门：全绿」。
- **不做**：不在验证集上调规则权重（那是拿验证集调参）；不因为某一档规则更高就换规则当主模型（要换得走 ADR 0005 的门槛：AP 高 ≥ 0.03 且名额内精确率高 ≥ 2pp）；不报「按精确率挑出来的最优名额」那种挑出来的点。
